# ページ上の差分

ページの URL に `diff` パラメーターを付けると、そのページの上に変更が示される。
追加と変更は緑で、削除した文は、削除した位置に赤の取り消し線で示す。

## diff パラメーター

パラメーターは git と同じ記法で書く。

| URL | 示す内容 |
| --- | --- |
| `/guide/install?diff=a1b2c3d` | コミット `a1b2c3d` がこのページに加えた変更 |
| `/guide/install?diff=v1.0..HEAD` | タグ `v1.0` の時点から現在までの変更 |
| `/guide/install?diff=v1.0..` | 上と同じ（終点を省くと `HEAD`） |
| `/guide/install?diff=a1b2c3d..e4f5a6b` | 2 つの版のあいだの変更 |

版には次の 3 つを使える。

- **コミットハッシュ**：4 文字以上。このページを変えたコミットに限る。短縮したハッシュが複数のコミットに一致したときは、候補を並べて示す。
- **タグ**：リポジトリの任意のタグ（[`tagPattern`](./options) で絞り込める）。ページを変えていない時点も指せる。
- **`HEAD`**：ページの最新の版。

## 印の付き方

このプラグインは、差分を別に描くのではなく、描画されたページそのものに印を付ける。

- **段落とリストの項目**：段落がソースの複数の行にわたるときは、変わった行だけに印を付ける。一文一行で書いた文書なら、文の単位で印が付く。
- **表**：変わった行に印を付ける。削除した行は、列ごとのセルに分けて取り消し線で示す。
- **コードブロック**：コードの行ごとに印を付け、削除した行はそのあいだに差し込む。
- **削除したブロック**：削除した段落は、削除した位置に、Markdown のソースのまま赤い枠で示す。

ページには常に最新の版が表示されている。
そのため、古いコミットを指定したときは、そのコミットで加えた行を最新の版までたどって示す。
その後のコミットで書き換えた行は、「その後さらに変更」として黄色で示す。

ページ上に示せない変更もある。
フロントマターと `import` の行は描画されないので、示せなかった行数を画面下部のバーに表示する。
これらはソースの差分で確かめられる。

## 画面下部のバー

差分を表示しているあいだ、画面下部のバーに、変更の日時、要約行、作者と、色の凡例を表示する。

- **↑ と ↓**：変更箇所を移動する。キーボードの `n` か `j` で次へ、`p` か `k` で前へ移る。削除した文とそれを置き換えた文は、1 か所の変更として数える。
- 変更箇所がすべて画面に収まっているときは、変更箇所の数だけを表示する。
- **ソースの差分**：Markdown のソースの差分をダイアログで開く。統合と左右に並べる形を切り替えられる。
- **閉じる**：パラメーターを外して、通常のページに戻る。

## 制約

- 開発サーバーで、コミットしていない編集があるページを開くと、印の位置がずれることがある。行番号を最新のコミットの内容に合わせているためである。
- 段落の最初の文を削除したときは、文の位置ではなく、段落の前に枠で示す。
- 印の位置合わせは Rspress の既定のテーマを前提にしている。テーマを大きく作り替えたサイトでは、印が付かない変更が出る可能性がある。その場合もソースの差分では確かめられる。
