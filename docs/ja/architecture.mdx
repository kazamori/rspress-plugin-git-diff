# アーキテクチャ

このプラグインは 2 つの部分からなる。
ビルド時には、git の履歴を読み出して静的なファイルに書き出し、描画するページの要素にソースの行番号を付ける。
ブラウザでは、そのファイルを読み、ページ上の差分と最近の変更のページを表示する。

各図には操作できる版へのリンクがあり、コンポーネントの検索や、ソースの参照をたどれる。
図の文言は英語である。
