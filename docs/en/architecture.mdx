# Architecture

The plugin has two halves.
At build time, it reads the git history and writes it as static files, and marks the rendered pages with their source lines.
In the browser, it reads those files to show the on-page diff and the recent changes page.

Each diagram links to an interactive version, where you can search the components and follow the source references.
